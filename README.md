# Proyecto DevOps en AWS

Este repositorio contiene la implementación de una plataforma automatizada de despliegue y monitoreo en AWS para la empresa ficticia Soluciones Tecnológicas del Futuro.

## Objetivo

Diseñar e implementar un flujo de trabajo DevOps que automatice el despliegue de una aplicación web, mejore la estabilidad del sistema y permita monitoreo continuo mediante servicios de AWS.

## Herramientas principales

- GitHub
- GitHub Actions
- AWS CloudFormation
- AWS EC2
- AWS S3
- AWS CloudWatch
- Docker
- Python
- Bash
- Boto3

## Flujo de trabajo

El desarrollo se realiza en la rama develop. Los cambios se integran a main mediante Pull Requests.
